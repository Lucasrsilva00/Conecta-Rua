# Projeto Conecta-Rua

Plataforma de logística social contra o desperdício de alimentos em Camaçari (BA).

- **Site oficial:** https://conecta-rua.vercel.app/
- **Repositório:** https://github.com/Lucasrsilva00/Conecta-Rua
- **Centro operacional:** SENAI Camaçari (Av. Eixo Urbano Central, Centro, Camaçari/BA).

## Estrutura
- `sites-animados/conecta-rua/` — site animado (intro por scroll + landing).
- `img/` — assets visuais (logos, referências).
- `docs/` — documentação.

## Tecnologias
HTML, CSS, JavaScript (sem bundler), Leaflet + OpenStreetMap/Esri (mapa), WebP (frames), Inter (tipografia). Deploy: Vercel.
